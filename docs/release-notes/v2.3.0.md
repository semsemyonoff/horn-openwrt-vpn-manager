## Что нового

- **Fallback-цепочки.** Любая подписка может объявить `fallback: {subscriptions: [...],
  blacklist_timeout: "1m"}` — генерируется группа `<id>-fallback`: сама подписка первой, резервные
  следом. Нужен [sing-box-extended](https://github.com/shtorm-7/sing-box-extended): в стоковой сборке
  типа `fallback` нет.
- **Свои ноды без подписки.** Вместо `url` можно задать `nodes: ["vless://…", "hysteria2://…"]` — без
  HTTP, с валидацией при загрузке конфига. В LuCI у карточки подписки появился выбор источника.
- **Hysteria2** рядом с VLESS: протоколы стали подключаемыми, схемы `hysteria2://` и `hy2://`.
- **Кэш списков маршрутизации** с TTL и ревалидацией по `If-None-Match` (`fetch.list_cache_ttl`, флаги
  `--cached-lists` и `--download-lists`); каждый URL логирует число записей и реальный источник.
- **Параллельный cron безопасен:** прогоны берут flock на `.run.lock` и ждут освобождения вместо
  пропуска цикла, а факт применения фиксируется маркером ревизии.
- **`singbox.connect_timeout`** — таймаут установления соединения на всех нодовых аутбаундах.

## Исправления

- устаревшая ревизия route list больше не применяется поверх свежей;
- LuCI-флаг несинхронизированного конфига переживает падение прогона, stderr ядра попадает в лог.

## Обновление

Группы `urltest` и `selector` теперь всегда с `interrupt_exist_connections: true` — поднимите
`tolerance` до ~300 мс, иначе urltest будет рвать живые соединения на обычном джиттере.
